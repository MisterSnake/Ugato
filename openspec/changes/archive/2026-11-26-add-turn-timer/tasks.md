# Tasks

Every task is one TDD cycle: **Red** (write the failing test and run it to see it fail), **Green** (write the least code that makes it pass), **Refactor** (clean up with the suite green). Backend tests run with `./.venv/Scripts/python.exe -m pytest -q` from `backend/`; frontend tests run with `npm test` from `frontend/`. All code, identifiers, comments and test names are in English.
